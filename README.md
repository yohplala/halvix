# Halvix Raw Data

This branch contains raw price data (parquet files).
It is automatically updated by CI and has no history (orphan branch).

**Last updated:** 2026-09-06 08:22:59 UTC

**Do not manually edit files in this branch.**

## Contents

- `raw/prices/`: 1787 coin price files
- `cache/`: Coin list cache
- `processed/`: Download metadata (coins list, fetch metadata, skipped/failed)
- `site/`: Generated HTML pages (data_status.html)
